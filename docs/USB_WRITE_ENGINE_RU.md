# Движок записи на USB

В Easyaller появился независимый от конкретного носителя движок подготовки установочных файлов Windows и уже экспортированного deployment package для будущей съёмной цели. Он не выбирает диск, не форматирует носитель и пока не принимает букву Windows-тома.

## План до выполнения

`UsbMediaWriteEngine.CreatePlan` принимает только явно выбранный диск, уже прошедший проверки безопасности съёмного носителя. Он читает каталог установочных файлов и каталог deployment package, фиксирует каждый выходной путь, размер в байтах и SHA-256. План блокируется, если:

- один из каталогов отсутствует, относительный или недоступен для чтения;
- источник содержит symbolic link или другой reparse point;
- deployment manifest неверен, неполный или его файл изменился;
- в проверенном package нет `autounattend.xml`;
- установочные файлы и package пытаются записать один путь назначения.

Сам `deployment-manifest.json` включается в план, хотя намеренно не содержит хэш самого себя.

## Контракт выполнения

Для выполнения требуется одноразовое разрешение из `AuthorizeFirstWrite`. Его immutable disk ID и необязательный serial должны совпасть с планом. До открытия цели движок заново проверяет хэш каждого источника. Изменённый источник останавливает поток до начала копирования.

Целью служит явный адаптер `IUsbMediaWriteTarget`. Он получает только повторно проверенный разрешённый диск и неизменяемый план. Движок копирует каждый источник, вызывает commit цели лишь после всех записей, затем через адаптер снова читает все итоговые файлы и сравнивает размер и SHA-256 с планом. `IsReady` возвращается только после совпадения всех финальных хэшей. Ошибка чтения, записи, commit или проверки дает неготовый результат; частично записанный носитель никогда не объявляется готовым.

## Текущая граница

Встроенного Windows-адаптера тома пока намеренно нет. Будущий адаптер обязан доказать, что выбранный USB-том принадлежит повторно проверенному immutable ID диска, и только затем реализовать `IUsbMediaWriteTarget`. Это не дает движку принять произвольный путь, который мог бы указывать на системный диск. Интерфейс и физическая запись на USB остаются будущей работой.
