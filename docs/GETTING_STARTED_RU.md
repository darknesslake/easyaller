# Начало работы с Easyaller

Easyaller — настольное приложение для подготовки и обслуживания компьютеров Windows 11. Оно хранит повторяемые настройки в профилях, применяет только выбранные операции, устанавливает программы по очереди и предоставляет отдельные инструменты обслуживания уже настроенного ПК.

## Запуск из исходного кода

Требуется .NET SDK 10:

```powershell
dotnet run --project src/Easyaller.App/Easyaller.App.csproj
```

Проверка проекта:

```powershell
dotnet build Easyaller.slnx
dotnet test Easyaller.slnx --no-build
```

## Главный экран и профили

Easyaller всегда открывается на главном экране выбора режима.

1. Выберите профиль или создайте новый. Здесь же доступны импорт, экспорт, создание копии и удаление.
2. Название и описание профиля изменяются только на главном экране.
3. Выберите режим: **Настроить этот компьютер**, **Обслуживание ПК** или **New USB Install**.
4. Чтобы сменить режим или профиль, нажмите **Выйти из режима** в левом верхнем углу.
5. Заполните повторяемый стандарт рабочей станции и сохраните профиль. Пустые поля профиля не означают команду очистить Windows.

Профиль хранит полный повторяемый стандарт, но не хранит пароли. Имя компьютера вводится отдельно при применении и должно соответствовать правилам выбранного профиля.

## Выборочное применение к этому ПК

Откройте **Настроить этот компьютер** и выберите слева раздел **Применить настройки**. Слева отображается только навигация по разделам; профиль выбирается на главном экране.

- Кнопки **Применить на этом ПК** запускают только соответствующую настройку.
- Незаполненное runtime-поле не очищает существующее значение Windows.
- Общее сохранение профиля ничего не применяет к текущему компьютеру.
- Перед изменением показывается подтверждение и точный список операций.
- Для системных операций Easyaller должен быть запущен администратором.

Поддерживаются часовой пояс Windows, параметры конфиденциальности, имя ПК, статический IPv4, маска, шлюз, DNS, WinHTTP-прокси, присоединение к домену и установка приложений.

## Очередь приложений

В режиме **Настроить этот компьютер** выберите слева раздел **Установка программ**. Он использует выбранный профиль, но не применяет настройки Windows и не запускает проверку. Можно запустить всю очередь или дважды щёлкнуть по названию одной программы.

Порядок задаётся стрелками **↑** и **↓** непосредственно возле каждой программы. Установщики копируются локально и запускаются последовательно.

При ошибке очередь останавливается. Можно:

- повторить неудачную программу;
- пропустить её и продолжить;
- остановить активный установщик;
- продолжить сохранённую очередь после перезапуска Easyaller.

История последних запусков показывает результат, коды завершения и проблемную программу.

## Обслуживание ПК

Режим **Обслуживание ПК** не входит в профиль новой установки.

### Ярлыки

Easyaller копирует `.lnk`, `.url` и `.website` из выбранной папки на рабочий стол выбранного пользователя Windows. Путь к папке запоминается; если папка исчезла, настройка сбрасывается. Перед копированием проверяются реальный Desktop, локализованный «Рабочий стол» и OneDrive, права записи, совпадения и итоговое действие для каждого файла.

### Архив Outlook

Поддерживается классический Outlook текущего пользователя. Easyaller считает письма в стандартных папках **Входящие** и **Отправленные**, создаёт или использует файл `Документы\Файлы Outlook\дд.ММ.гггг.pst`, создаёт одноимённые папки и переносит письма за всё время либо старше 2 недель, 1 месяца или 3 месяцев.

Доступны прогресс, остановка между письмами, список ошибок, проверка PST, защита от повторного запуска и история последних архиваций. Новый Outlook не поддерживается.

## Подготовка новой Windows

Режим **New USB Install** создаёт проверяемый deployment-пакет и защищённую раскладку USB. Перед записью обязательно проверяются ISO, целевой диск и сводка операции. Используйте сначала тестовую VM или выделенную флешку.
