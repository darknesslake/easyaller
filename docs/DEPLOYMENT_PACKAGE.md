# Deployment package safety

Easyaller can create a file-only deployment package through its deployment API. The desktop application does not expose package creation yet.

## What the exporter writes

The exporter accepts a validated `DeploymentDryRun`, a destination directory that does not already exist, and an explicit list of source files. It writes these required files:

- `autounattend.xml` - the exact bytes generated by the dry run;
- `selected-profile.wpprofile.json` - the validated selected profile;
- `README.txt` - package handling instructions;
- `deployment-manifest.json` - SHA-256 and size for every package file except the manifest itself.

It can also copy explicitly supplied assets:

- local payload files must be below `payload/`;
- scripts must be below `scripts/`;
- installers must be below `installers/` and exactly match a `packageRelative` application path in the selected profile.

Asset paths cannot be absolute, traverse with `.` or `..`, duplicate another package path, or replace a required file. A source asset must be an existing regular file, not a symbolic link. External-manual applications cannot be silently copied as installers.

## Atomic export and verification

The destination must not exist. Easyaller creates a uniquely named staging directory beside it, writes files only there, calculates SHA-256 hashes, rereads every manifest entry to verify its length and hash, then renames the staging directory to the final destination. A failed or cancelled export removes only that staging directory and never replaces an existing package.

`deployment-manifest.json` deliberately does not hash itself. Verify each manifest entry before use. Treat the entire package as sensitive, especially when it contains an answer file with an obfuscated temporary local-account password. Do not commit a package to Git.

## Explicitly out of scope

Export only creates ordinary files. It does not format a disk, mount or modify an ISO or WIM, invoke `diskpart`, write a boot record, create USB media, join a domain, or change Windows settings. The package must be validated with the documented Windows-host process before use.
