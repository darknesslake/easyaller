# Безопасность пакета развёртывания

Easyaller умеет создавать файловый пакет развёртывания через deployment API. В интерфейсе программы создание пакета пока не доступно.

## Что записывает экспортёр

Экспортёр принимает проверенный `DeploymentDryRun`, каталог назначения, которого ещё нет, и явный список исходных файлов. Обязательные файлы:

- `autounattend.xml` - точные байты, созданные dry run;
- `selected-profile.wpprofile.json` - проверенный выбранный профиль;
- `README.txt` - инструкция по обращению с пакетом;
- `deployment-manifest.json` - SHA-256 и размер каждого файла пакета, кроме самого манифеста.

Также можно явно передать дополнительные файлы:

- локальные файлы payload должны лежать внутри `payload/`;
- скрипты должны лежать внутри `scripts/`;
- установщики должны лежать внутри `installers/` и в точности соответствовать пути `packageRelative` приложения в выбранном профиле.

Путь файла не может быть абсолютным, содержать переход `.` или `..`, дублировать другой путь пакета или заменять обязательный файл. Источником может быть только существующий обычный файл, а не символическая ссылка. Приложения с ручной внешней установкой нельзя незаметно скопировать как установщик.

## Атомарный экспорт и проверка

Каталог назначения не должен существовать. Easyaller создаёт рядом уникальный staging-каталог, записывает файлы только в него, вычисляет SHA-256 хэши, заново читает каждый файл из манифеста для проверки размера и хэша, затем переименовывает staging-каталог в итоговый. При ошибке или отмене удаляется только этот staging-каталог, а существующий пакет никогда не заменяется.

`deployment-manifest.json` намеренно не содержит хэш самого себя. Перед использованием проверьте каждый файл из манифеста. Считайте весь пакет чувствительным, особенно когда в нём есть файл ответов с обфусцированным паролем временной локальной учётной записи. Не коммитьте пакет в Git.

## Что явно не входит в задачу

Экспорт создаёт только обычные файлы. Он не форматирует диск, не монтирует и не изменяет ISO или WIM, не запускает `diskpart`, не записывает загрузочную запись, не создаёт USB-накопитель, не присоединяет компьютер к домену и не меняет параметры Windows. Перед использованием пакет нужно проверить по документированному процессу на Windows-хосте.
