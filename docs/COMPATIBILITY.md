# Windows compatibility catalog

Easyaller begins with documented Windows 11 Pro and Enterprise targets on amd64:

| Display version | Base OS build | Editions | Evidence |
| --- | ---: | --- | --- |
| 24H2 | 26100 | Pro, Enterprise | Documented |
| 25H2 | 26200 | Pro, Enterprise | Documented |

The catalog marks only Microsoft documentation as present. Windows SIM and VM validation remain separate evidence states and must not be inferred from a documented build number.

An unknown display version or build produces a warning. Easyaller must not enable an unvalidated workaround.

Source: [Windows 11 release information](https://learn.microsoft.com/en-us/windows/release-health/windows11-release-information).
