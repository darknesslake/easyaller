# Создание установочного USB

В Easyaller появился экран для копирования раскладки установочного USB на уже пустой отформатированный съёмный том из каталога Windows Setup и экспортированного deployment package Easyaller. Он не форматирует, не размечает, не инициализирует и иначе не подготавливает том.

## Безопасный поток

1. Откройте **Создать установочный USB** в боковом меню.
2. Обновите список дисков. Экран показывает только явно допустимые съёмные USB, SD или MMC. System, boot, fixed, offline, read-only, unknown-bus и диски без identity не показываются как цели.
3. Выберите один видимый диск вручную. По умолчанию ничего не выбрано.
4. Выберите корневой каталог смонтированного или распакованного Windows Setup и ранее экспортированный deployment package Easyaller. Оба источника не изменяются. Получайте ISO в одобренном канале и проводите его отдельную read-only проверку до использования.
5. Создайте план. До подтверждения Easyaller считает хэши источников и проверяет deployment manifest, затем создаёт подтверждение на пять минут.
6. Проверьте vendor, serial или immutable device ID, номер диска и точный размер в байтах. Введите строго `ERASE` заглавными буквами.
7. Прямо перед копированием Easyaller обновляет инвентарь дисков, находит ровно один раздел с буквой на разрешённом диске, убеждается в пустоте корня и снова связывает том с тем же ID диска. Затем он использует staging, выполняет commit и проверяет SHA-256 каждого итогового файла.

## Условия остановки

Поток останавливается и не объявляет USB готовым, если устройство изменилось, больше не проходит проверку безопасности, содержит ноль или больше одного раздела с буквой, его корень не пуст, источник изменился, пути конфликтуют, копирование не удалось или хэш на выходе отличается.

Для первого физического запуска используйте выделенную восстанавливаемую тестовую флешку. Эта пре-альфа функция покрыта unit-тестами и временным каталогом, но еще не проверялась на физическом USB в этой среде разработки. Храните готовые evidence, экспортированные package и ISO вне Git.
