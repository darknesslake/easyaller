# Привязка Windows USB-тома

В Easyaller появился Windows-адаптер привязки тома и staging-цель для движка записи USB. Адаптер принимает корень тома только после доказательства, что он принадлежит тому же immutable ID диска, который прошёл одноразовую авторизацию.

## Проверка только для чтения

Фиксированный неинтерактивный PowerShell-запрос получает корень через окружение дочернего процесса, затем читает `Get-Volume -FilePath`, `Get-Partition`, `Get-Disk` и `Win32_DiskDrive`. Он получает номер диска, `UniqueId`, serial number, шину, размер и флаги system, boot, read-only, offline и removable. Команд форматирования, разметки, очистки, монтирования, размонтирования, инициализации или изменения атрибутов нет.

Цель блокируется при любом из условий:

- корень не разрешается ровно в один partition и disk;
- возвращенный корень отличается от запрошенного;
- `UniqueId` или доступный serial не совпадает с планом и текущей одноразовой авторизацией;
- обновленный диск больше не является допустимым съёмным USB, SD или MMC;
- корень не пуст до начала staging.

`Get-Volume` разрешает путь к тому, а `Get-Partition` может находить partition по тому, букве или номеру диска. [Get-Volume](https://learn.microsoft.com/en-us/powershell/module/storage/get-volume), [Get-Partition](https://learn.microsoft.com/en-us/powershell/module/storage/get-partition), [Get-Disk](https://learn.microsoft.com/en-us/powershell/module/storage/get-disk)

## Поведение staging-цели

Файлы записываются в уникальный каталог `.easyaller-staging-*` внутри проверенного пустого корня. До commit цель убеждается, что в корне не появился посторонний файл. Затем она переносит верхнеуровневые записи staging в корень. Движок снова читает каждый итоговый файл и объявляет носитель готовым только при совпадении SHA-256 с неизменяемым планом.

При ошибке проверки, копирования, commit или хэша Easyaller возвращает неготовый результат. Staging удаляется, когда это возможно, а частично committed том никогда не объявляется готовым. Интерфейс пока не подключен, а адаптер не запускался на физическом USB в этой среде разработки.
