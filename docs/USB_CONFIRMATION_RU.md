# Подтверждение опасной операции с USB

В Easyaller появилась машина состояний, которая защищает будущий движок записи на USB. Она по-прежнему не форматирует, не инициализирует, не размечает, не очищает, не монтирует и не изменяет диски.

## Поток подтверждения

Поток начинается только для явно выбранного диска, прошедшего модель безопасности съёмных дисков. Создаётся подтверждение на пять минут с vendor, serial number или неизменяемым device ID, номером диска и точным размером в байтах. Диска по умолчанию и автоматического подтверждения нет.

Оператор должен ввести строго `ERASE` заглавными буквами. Другой регистр, пробелы в начале или конце и любая другая фраза блокируются. Правильная фраза сама по себе не разрешает будущую запись. Непосредственно перед первой записью будущий движок обязан вызвать `AuthorizeFirstWrite`: он обновляет инвентарь и снова применяет проверки immutable ID и serial number.

Если выбранный диск пропал, дублируется, сменил serial number, стал небезопасным или был заменён другим диском с тем же номером, разрешение блокируется. Подтверждение истекает через пять минут. Успешное разрешение одноразовое и не может быть повторно использовано.

## Границы

- Подтверждение хранится только в памяти процесса. Перезапуск приложения его отменяет.
- В интерфейс пока не подключено.
- Движка записи пока нет. WP-053 получит одноразовое разрешение только после финальной повторной проверки инвентаря.
