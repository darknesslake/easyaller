# Исключения WinHTTP-прокси в профиле

В профиле Easyaller можно сохранить необязательный список исключений WinHTTP-прокси вместе с уже существующим режимом прокси `promptAtRuntime`. Адрес самого прокси по-прежнему вводится только во время выполнения. Список исключений является данными профиля, поэтому перед экспортом он отмечается как конфиденциальный.

English version: [PROXY_BYPASS.md](PROXY_BYPASS.md).

## Контракт профиля

Поле `machine.proxy.bypassList` необязательно и допускается только при `machine.proxy.mode` со значением `promptAtRuntime`.

- В редакторе профиля укажите до 256 значений через запятую, точку с запятой или новую строку.
- Разрешены имя хоста, IPv4-адрес, шаблон с `*`, например `*.example.test`, и документированный WinHTTP-токен `<local>`.
- Пробелы, URL, текст команд и повторяющиеся значения не допускаются.
- Программа не сохраняет в профиле пароль, токен или runtime-адрес прокси.

Нейтральный пример фрагмента профиля:

```json
"proxy": {
  "mode": "promptAtRuntime",
  "bypassList": ["*.example.test", "<local>", "192.0.2.53"]
}
```

## Что меняет применение

После проверки runtime-адреса прокси и точного ввода `APPLY` Windows-адаптер использует фиксированную PowerShell-команду `Set-WinhttpProxy`. Если сохранённый список не пуст, он передаётся через параметр `BypassList`. Если список пуст, устанавливается только адрес прокси.

Настройка относится к потребителям WinHTTP. Она не означает настройку каждого браузера, настольной программы, PAC-скрипта, VPN-клиента или пользовательского прокси. Перед применением проверьте целевые программы.

Microsoft документирует `Set-WinhttpProxy` и необязательный параметр списка исключений в [модуле WinHttpProxy для PowerShell](https://learn.microsoft.com/en-us/powershell/module/winhttpproxy/set-winhttpproxy?view=windowsserver2025-ps). Команда доступна только в Windows. До использования на рабочей станции нужен результат проверки в Windows VM.

## Граница безопасности

- Easyaller не ищет адреса прокси и исключения автоматически.
- Оператор вводит адрес прокси только во время выполнения. Он не попадает в хранилище профилей и состояние resume.
- Поле профиля не является произвольным аргументом PowerShell и не может нести команду.
- Предпросмотр экспорта помечает список как конфиденциальный, так как он может раскрывать структуру внутренней сети.
- Для этой возможности ещё нет проверки в Windows VM или на физическом ПК.
